## 📖 About the Project

**Cup of Joy Café** is a responsive, single-page coffee shop concept created as a personal frontend development project. The website combines a warm café aesthetic with straightforward navigation and interactive page elements to demonstrate practical skills in web design, responsive layouts, and DOM scripting.

It is designed as a **frontend showcase**, not a production ordering or restaurant management system.

## ✨ Features

| Feature | Details |
| --- | --- |
| ☕ **Welcome / Hero Section** | Café branding, introduction, and a menu-focused call to action. |
| 🏡 **About Section** | Brand introduction, imagery, and café-themed content. |
| 🛍️ **Coffee Showcase** | Product cards with photos, descriptions, and sample prices. |
| 🖼️ **Photo Gallery** | A collection of café and coffee-related images. |
| 💬 **Testimonials** | Customer review layouts using sample content. |
| 📩 **Contact Section** | Contact form UI with client-side input validation. |
| 📰 **Newsletter Section** | Newsletter subscription interface for layout demonstration. |
| ✨ **Scroll Animations** | Reveal animations and interactive visual effects using ScrollReveal. |
| 📱 **Responsive Design** | Layouts adapted for desktop and smaller screens. |
| 🧭 **Section Navigation** | Single-page links for browsing the main content areas. |

> [!IMPORTANT]
> **Frontend demo only:** The coffee listings, prices, testimonials, business contact details, hours, and statistics are illustrative content. Buttons such as **Add to Cart** or **Order Online** should not be interpreted as a verified checkout system. The contact form and newsletter UI do not imply that messages are emailed or subscriptions are saved on a server. Backend services and payment processing are not part of the documented project.

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser. **VS Code** and its **Live Server** extension are optional for local development.

### 1. Clone the Repository

```bash
git clone https://github.com/p-g-udara-dilshan/Cup_of_Joy_Cafe---Coffee_Shop.git
cd Cup_of_Joy_Cafe---Coffee_Shop
```

### 2. Run the Website

Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in VS Code or start a simple local HTTP server:

```bash
python -m http.server 5500
```

Then open **http://localhost:5500** in your browser. If your Python installation uses `python3`, run `python3 -m http.server 5500` instead.

### 3. Explore the Page

Navigate through **Home**, **About**, **Products**, **Gallery**, and **Contact** to view the interface and its interactions.

The deployment URL above is the previously published website link. If GitHub Pages is moved to a new account or a custom domain, update this URL in the repository About section and README.

For a GitHub Pages deployment of your own fork:

1. Push the website files to a public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the relevant branch and root directory, then save.
5. Open the Pages URL after the deployment completes.
